# Desenvolvimento Web: primeiro site

Primeiro site que fiz na matéria de Desenvolvimento Web (2021), redesenhado
depois.

- HTML e CSS puros, sem dependências nem build
- Layout responsivo com CSS Grid
- Tema claro/escuro (segue o sistema e lembra a escolha)
- Acessível: navegação por teclado, link "pular para o conteúdo", respeita
  `prefers-reduced-motion`

## Como ver

Abra `index.html` no navegador, ou publique com GitHub Pages
(Settings → Pages → branch `main`).
